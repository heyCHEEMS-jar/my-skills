# markdown-drafter

## 简介

一个面向个人技术博客的写作 Skill，帮助 AI 编程助手把开发记录、代码、报错和零散笔记整理成中文 Markdown 初稿。

**像本人记录事情，而不是只模仿排版。**

- 默认分三阶段协作：先确认文章重点，再给结构和一小段试写，用户确认语气后才完成全文；明确要求直接出稿时才跳过。
- 提供博客、样文或作者终稿时，先看实际用词与删改：哪些铺垫、代码、表格、资料和总结被删掉，再校准文章语气。
- 从正在做的功能和具体问题切入，跟着事情往下写，不先预告提纲或铺行业背景。
- 默认直接、自然地叙述技术事实；短段、问句和口语转折按作者样文使用，不把它们当作个人博客的固定标记。
- 支持踩坑记录、选型经历、快速上手、手写实现、速查合集和概念解释，不统一套模板。
- 代码、表格和资料按内容需要出现，不为显得完整或专业而主动补齐。
- 保留关键因果和直接取舍，删掉重复总结、营销金句和未经提供的心理活动，讲完就停。
- 保持技术事实和证据边界，不编造作者经历、测试结果、性能数字或引用，也不反复解释同一个边界。
- 只输出初稿或保存到授权位置，不擅自修改业务项目、构建或发布博客。

> [!IMPORTANT]
> 技术事实与证据是底线；写作偏好按用户本次要求、目标博客已有格式和本 Skill 的默认风格选择。它不替代技术验证，不为了模仿作者而保留错误解释。

风格结合博客中的技术文章提炼；只总结稳定的表达习惯，不照搬原文、错误示例或教学简化。写作要点见 [references/style-analysis.md](references/style-analysis.md)，原创示例见 [references/writing-examples.md](references/writing-examples.md)。

## 安装

本项目以文档形式提供 Skill，没有可执行源码、依赖清单或构建脚本，不需要运行 `npm install`。

1. 获取完整的 `markdown-drafter` 目录。
2. 将目录放入所用 AI 编程助手支持的 Skill 目录。
3. 加载 Skill；具体安装路径与发现机制以宿主工具为准。

## 使用

### 用自然语言提出需求

加载 Skill 后，可以结合开发记录、代码或已有初稿提出请求。Skill 默认不会马上写整篇，而是先确认你想突出什么，再给一个结构和小段试写；你确认语气后才补全正文。

```text
把这段XX经历写成博客。
```
