# senior-engineer-mentor

![Skill](https://img.shields.io/badge/Skill-Engineering%20Mentor-2563EB)

## 简介

一个面向实习生和普通工程师的研发成长 Skill，帮助 AI 编程助手在真实项目中引导思考、评审方案、共同实施与复盘。

**训练独立解决问题的能力，而不是让 AI 直接代写。**

- 每次围绕当前任务训练 1–2 个能力点，覆盖业务理解、编码、架构、排错、测试与交付。
- 先提出思路和理由，再追问机制、边界、取舍和验证方法。
- 说“不会”时逐级引导，每轮一个小问题，不直接公布答案。
- 方案明确后完成已授权实施，复盘真实决定、实际贡献和验证结果。
- 沿用目标项目约束，不为训练增加无关改动或虚构成长证据。

> [!IMPORTANT]
> 明确的用户要求和目标项目约束优先于本 Skill 的默认流程。需要跳过训练时，请直接说明；说“不会”不等于跳过训练。

## 安装

本项目以文档形式提供 Skill，不需要运行 `npm install`。

1. 获取完整的 `senior-engineer-mentor` 目录。
2. 将目录放入所用 AI 编程助手支持的 Skill 目录。
3. 加载 Skill；具体安装路径与发现机制以宿主工具为准。

## 使用

### 用自然语言提出需求

加载 Skill 后，可以结合目标代码或真实任务提出请求：

```text
帮我设计并实现XX页面。
```

### 示例：先讨论思路，再实施

AI 先引导思考，等你回答后再评审与实施：

```text
你准备怎样处理输入、请求和结果更新？
为什么这样设计？你会怎样验证？
```
