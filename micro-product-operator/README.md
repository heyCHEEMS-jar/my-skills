# micro-product-operator

![Skill](https://img.shields.io/badge/Skill-Micro%20Product%20Operator-7C3AED)

## 简介

一个面向独立前端开发者的产品经营 Skill，帮助 AI 编程助手批量发现、验证、开发、上架和运营简单、低成本、容易传播的 Web 小软件与轻量网页游戏。

**参考国外已经验证的爆款机制，寻找国内尚未充分满足的机会；先让一款跑通，再复制生产能力。**

- 优先寻找一句话能说清、1–2 周能做出 MVP、前端工作为主的简单产品。
- 核实国外需求证据和国内竞争现状，不凭印象宣称“国内没有”，也不照搬品牌、代码、内容或界面。
- 同时判断传播闭环和购买理由，避免做成“能玩但没人分享”“简单但没人付费”的作品。
- 默认选择响应式 Web/PWA，支持电脑和手机，并适配电商平台发放激活码的销售方式。
- 优先利用现有基础设施，采用静态资源、客户端计算和轻量数据服务控制成本。
- 用真实漏斗决定继续、转向或停止；第二、第三款出现重复需求后再抽公共底座。
- 覆盖机会筛选、产品简报、MVP、上架、激活、运营实验和批量生产，而不只负责写代码。

> [!IMPORTANT]
> “国外爆款”是需求证据，不是复制许可；“国内还没有”必须经过当期检索。明确的用户要求、真实运营数据、平台规则和目标项目约束优先于本 Skill 的默认策略。

## 安装

本项目以文档形式提供 Skill，没有可执行源码、依赖清单或构建脚本，不需要运行 `npm install`。

1. 获取完整的 `micro-product-operator` 目录。
2. 将目录放入所用 AI 编程助手支持的 Skill 目录。
3. 加载 Skill；具体安装路径与发现机制以宿主工具为准。

## 使用

### 用自然语言提出需求

加载 Skill 后，可以从找方向、做产品或看数据的任意阶段开始：

```text
找 3 个国外已经爆过、国内还没被充分覆盖的简单网页游戏方向。
要求 1–2 周能做出 MVP、基础设施成本低，最后只推荐一个。
```

也可以继续运营已有产品：

```text
继续运营XX：这是最近 7 天的访问、创建、完成、分享和兑换数据。
帮我判断继续、转向还是停止，并只安排下一项实验。
```

### 示例：从“国外爆款”收敛到可验证商品

AI 不会只列一堆游戏名称，而会完成：

```text
检索海外需求证据与国内同类
→ 按简单度、传播、付费、合规和资源成本评分
→ 推荐一个首选并说明淘汰项
→ 定义免费/付费边界和激活码权益
→ 给出 48 小时最低成本验证
→ 验证后再进入 MVP 开发
```
