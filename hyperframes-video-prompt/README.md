# hyperframes-video-prompt

![HyperFrames](https://img.shields.io/badge/HyperFrames-Video-7C3AED)

## 简介

一个为 HyperFrames 整理角色叙事、动态分镜、时间轴和独立旁白稿的 Skill。

**只要用户要用 HyperFrames 制作视频就触发；制作前显式确认成片参数，用户没有决定的事项不擅自补默认值。**

在生成提示词前，Skill 会从对话中排除已经回答的项目，再分批询问所有仍适用的制作选择，包括内容目标与受众、时长、发布平台、准确画面比例、分辨率与帧率、背景与构图、角色和物品、动画与镜头、主视觉文字、旁白、字幕、音乐与音效、真实 UI 或素材、输出格式和保存目录。可以给出推荐，但只有用户确认或明确授权代选后才会采用；平台和“横屏/竖屏”不能代替具体比例确认。

默认不把知识视频做成会动的数据看板，而是让贯穿全片的火柴人或简洁角色通过动作和具象物品把内容演出来。

> [!IMPORTANT]
> 用户本次要求优先。用户明确指定纯实拍、品牌角色或无角色风格时，以该要求为准；仍保留行动驱动、非 PPT 和事实准确原则。本 Skill 不替代事实核验、素材授权或专业判断。

## 安装

本项目只有文档，不需要运行 `npm install`。

1. 获取完整的 `hyperframes-video-prompt` 目录。
2. 放入所用 AI 编程助手支持的 Skill 目录。
3. 按宿主工具的方式加载 Skill。

## 使用

### 示例：知识类视频

```text
用 HyperFrames 做一个XXX的3分钟视频。
```

### 示例：软件 UI 教程

```text
用 HyperFrames 做一个90秒教程，演示XXX。
```

```text
制作前先确认：
1. 目标观众是谁，观众最后要记住什么？需要片尾行动提示吗？
2. 视频多长、发布到哪里？准确比例用 9:16、16:9、1:1，还是其他比例？
3. 背景希望用全黑幕、其他纯色、场景化背景还是真实环境？构图偏极简还是丰富？
4. 火柴人的线条、颜色、动作夸张程度和配角数量有什么要求？
```

后续再确认动画节奏、动态或固定文字、旁白、字幕、音乐、音效、素材、分辨率、帧率、格式和保存目录。实际只询问尚未明确且适用于本片的项目，但会在制作前覆盖完整清单；用户明确授权“全部按你的推荐”后，Skill 才会代选。全部确认后会先复述最终参数，获得确认再生成。

信息齐全后交付：

```text
[主题]-HyperFrames提示词.md
[主题]-普通话旁白.md
```
