# senior-engineer-interviewer

![Skill](https://img.shields.io/badge/Skill-Senior%20Engineer%20Interviewer-2563EB)

## 简介

一个面向软件工程师的模拟面试 Skill。技术知识和常见八股只作为基础门槛，重点通过递进追问观察候选人如何定义问题、识别约束、建立假设、比较方案、量化验证并根据证据修正判断。

**考察如何思考和决策，而不只是知道多少答案。**

- 从简历、项目或目标岗位中的真实主张开始，不随机扫题。
- 一次只问一个主要问题，保留合理未知，让候选人展示完整推理过程。
- 深挖为什么这样选型、为什么不用其他方案、什么条件下会改变选择。
- 要求用基线、指标、实验和反例支撑性能、稳定性与规模结论。
- 对独立回答、澄清后回答和提示后回答分别记录，不混为同一种能力。
- 回答“不会”时逐级缩小问题并引导推理，不直接公布答案。
- 标准综合面包含真实中大型科技公司常见的限时手撕算法，完整观察澄清、思路、编码、自测、复杂度和变体迁移，而不只看 AC。
- 通过新证据和相邻场景观察自我修正、迁移能力与潜力方向。
- 结束后用简洁陈述形成思维与技术能力画像、潜力判断和对应技术路线，不输出冗长评分表格。

> [!IMPORTANT]
> 明确的用户要求优先于本 Skill 的默认流程。它用于模拟面试和能力训练，不应把真实项目协作或普通知识问答强行改造成面试。

具体领域的追问方向见 [references/interview-playbook.md](references/interview-playbook.md)。

## 安装

本项目以文档形式提供 Skill，没有可执行源码、依赖清单或构建脚本，不需要运行 `npm install`。

1. 获取完整的 `senior-engineer-interviewer` 目录。
2. 将目录放入所用 AI 编程助手支持的 Skill 目录。
3. 加载 Skill；具体安装路径与发现机制以宿主工具为准。

## 使用

### 用自然语言开始面试

加载 Skill 后，可以结合简历、项目经历或目标岗位提出请求：

```text
按前端XX标准面试我，从这个项目开始逐级追问，并在过程中判断我更适合深入的技术方向。
```

### 示例：从项目主张开始

用户提供：

```text
我负责过XXX。
```

Skill 不直接认可结论或给出答案，而是先要求明确个人责任、原始现象和测量口径，再根据回答逐步进入实现机制、动态数据、失败边界和方案取舍。
